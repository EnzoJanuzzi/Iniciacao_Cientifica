# Iniciação Científica FAPESP — Simulações DFT
Bolsista: Enzo Januzzi Xavier

Orientador: Prof. James Moraes de Almeida (ILUM/CNPEM)

Período de vigência: 01/11/2025 a 31/10/2026

Este repositório reúne os arquivos relevantes, dados e scripts utilizados durante a Iniciação Científica financiada pela FAPESP, processo: 2025/20105-9, vinculado a: XX. O projeto envolve o uso de métodos de Teoria do Funcional da Densidade (DFT) para o estudo de propriedades eletrônicas e estruturais de sistemas metálicos com potencial aplicação catalítica. A maioria desses códigos gera centenas de arquivos por pasta, mas apenas os arquivos de saída utilizados foram adicionados para facilitar a reprodutibilidade do projeto.
